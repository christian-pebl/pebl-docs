# Mounting

The optional mounting kit clamps the SubCam to a pole. The exploded view below shows the full assembly.

![SubCam pole mounting assembly, exploded view.](/img/subcam-mounting.png)

1. SS A4 u-bolt
2. SubCam
3. Galvanised nut M8
4. Plastic SubCam coupler
5. Nylon shoulder washer
6. SS 316 plate
7. SS A4 washer M6
8. Plastic pole coupler
9. M6 nyloc nut
10. Pole (not included)
11. Galvanised u-bolt

![SubCam mounted on a pole, assembled view.](/img/subcam-mounting-assembled.png)

:::info
For benthic (seabed) deployments on a Microlander frame instead of a pole, see the [Mooring Guide](../mooring-guide/index.md).
:::
