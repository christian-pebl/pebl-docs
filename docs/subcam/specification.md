# Specification

| Specification | Value |
| --- | --- |
| Dimensions | Ø64 × 230 mm |
| Depth rated | 50 m |
| Weight | 985 g (in air) |
| Materials | POM-C enclosure, mineral glass lens, stainless A4 hardware |
| Operating temperature | -5 °C to +40 °C |
| Video resolution (max) | Up to 1080p at 60 fps. 1080p at 30 fps in HDR mode |
| Image resolution (max) | 12 MP. 3 MP in HDR mode |
| Format | JPEG (stills), H.264 (video) |
| Field of view | 100° (in water), 120° (in air) |
| Autofocus | Phase Detection Autofocus (PDAF) for rapid autofocus |
| In-focus distance | 15 cm to infinity |
| Recording length (max) | Up to 15 hours |
| Charging | 9V USB-C PD |
| Charge time | 4 hours |
