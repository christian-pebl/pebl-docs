# Specification

| Parameter | Range / Spec |
| --- | --- |
| Temperature sensor | 0 °C to +50 °C operating, 0.1 °C resolution |
| Turbidity sensor | 0 to 100 NTU operating, 0.5 NTU resolution. Calibration solution supplied for 0 to 40 NTU |
| Current speed (tilt angle) | 0 to 85° tilt operating, 0.5° resolution (85° tilt ≈ 2.5 knots) |
| Current direction | 0 to 360° heading operating, 0.5° resolution (0°/360° = North) |
| Light sensor | 0 to 100,000 lux operating, 100 lux resolution |
| Dimensions | Ø64 × 720 mm |
| Depth rated | 50 m |
| Weight | 1500 g (in air) |
| Materials | POM-C enclosure, mineral glass lens, titanium hardware |
| Output file type | .CSV, comma separated |
| Logging rate | 10/second to 1/day, burst and averaging mode |
| Memory | microSD card. Supplied with 32 GB SanDisk |
| Battery | 12.8 Ah lithium-ion. Up to 320 days at a 30-minute sampling rate on a single charge |
